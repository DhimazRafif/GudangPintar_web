<h1>Gudang Pintar</h1>
<p>Gudang Pintar adalah aplikasi web yang digunakan untuk membantu proses pencatatan stok barang pada toko, sehingga proses pencataan tidak dilakukan secara manual di buku</p>
<h2>Functional Requirement : </h2>
<ol>
  <li>Autentikasi Pengguna
Fitur ini memungkinkan pengguna untuk mengakses aplikasi sesuai dengan role mereka
menggunakan akun yang terdaftar. Fungsi yang tersedia meliputi : Login dan Logout
  </li>
  <li>Manajemen Stok Barang
Fitur ini memungkinkan pengguna untuk melakukan pengelolaan stok barang di toko. 
  </li>
  <li>Manajemen Akun
Fitur ini memungkinkan pemilik toko untuk mengelola akun pegawainya.
  </li>
  <li>Notifikasi
Fitur ini memungkinkan pemilik dan pegawai toko untuk mendapatkan pemberitahuan jika
ada barang yang stoknya sisa sedikit untuk segera melakukan restock.
  </li>
  <li>Halaman dashboard
Fitur ini berfungsi sebagai halaman yang berisi informasi yang menyajikan ringkasan data
inventaris secara real-time bagi pemilik dan pegawai toko.
  </li>
  <li>Sistem history
Fitur ini memungkinkan pemilik toko untuk melihat aktivitas apa saja yang sudah terjadi di
dalam aplikasi. 
  </li>
  <li>Halaman transaksi
Fitur ini memungkinkan pemilik dan pegawai toko untuk mengubah stok berbagai barang
sesuai dengan transaksi barang yang terjadi di toko.
  </li>
</ol>
